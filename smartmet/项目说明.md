## 1. 项目概述

### 1.1 目标

利用 ERA5 高分辨率再分析数据（~0.25° × 0.25°），分析 **2010–2022 年中国夏季极端高温事件的时空演变特征**，结合环流场探究高温的物理机制。

### 1.2 分析维度

| 维度 | 内容 |
|------|------|
| 时间 | 2010–2022 年夏季（6–8 月） |
| 空间 | 中国区域（20°N–50°N, 80°E–130°E） |
| 变量 | 气温、位势高度、海温、降水、气压、风场 |
| 统计 | 气候态、距平、趋势、显著性检验、极端事件识别 |
| 可视化 | 静态图、动画、交互式图表 |

### 1.3 数据变量说明

| 变量 | ERA5 名称 | 单位 | 用途 |
|------|-----------|------|------|
| 2m 气温 | `2m_temperature` | K | 高温事件定义 |
| 位势 | `geopotential` | m²/s² | 计算 500 hPa 位势高度 |
| 海表温度 | `sea_surface_temperature` | K | 海温异常分析 |
| 总降水 | `total_precipitation` | m | 干湿条件分析 |
| 地表气压 | `surface_pressure` | Pa | 天气系统分析 |
| 10m U 风 | `10m_u_component_of_wind` | m/s | 风场环流 |
| 10m V 风 | `10m_v_component_of_wind` | m/s | 风场环流 |

## 2. 数据获取

### 2.1 下载工具

使用 `cdsapi`（CDS API）从 Copernicus Climate Data Store 下载 ERA5 数据。

### 2.2 下载策略

- **时间范围**：2010–2022 年，逐年下载
- **季节**：夏季（6 月、7 月、8 月）
- **时次**：每日 00:00 / 06:00 / 12:00 / 18:00（4 个时次）
- **区域**：中国区域 [50, 80, 20, 130]（北纬, 西经, 南纬, 东经）
- **格式**：NetCDF
- **存储**：按年份分别保存，存放在 `era5_summer_data/` 目录

### 2.3 断点续传

下载前检查目标文件是否存在，避免重复下载同一年的数据。

### 2.4 注意事项

- CDS API 需要注册账号并获取 API Key
- 每个请求数据量较大，逐年下载可避免超时
- 建议在网络稳定的环境下执行

## 3. 数据处理

### 3.1 数据读取

使用 `xarray` 读取 NetCDF 文件，支持 lazy loading 避免内存溢出。

### 3.2 多年度数据合并

逐年读取后，使用 `xr.concat` 沿时间维度合并为一个 `Dataset`。

### 3.3 单位转换

| 变量 | 原始单位 | 转换公式 | 转换后单位 |
|------|---------|----------|-----------|
| 2m 气温 | K | $T(°C) = T(K) - 273.15$ | °C |
| 位势 | m²/s² | $Z(gpm) = Z / 9.80665$ | gpm（位势米） |
| 总降水 | m | $P(mm) = P(m) \times 1000$ | mm |
| 地表气压 | Pa | $P(hPa) = P(Pa) / 100$ | hPa |

### 3.4 日平均计算

对每日 4 个时次求平均，得到逐日数据：

```python
ds_daily = ds.resample(valid_time='1D').mean()
```

### 3.5 气候态与距平

- **气候态**：2010–2022 年同期（夏季）多年平均
- **距平**：每年夏季值减去气候态

## 5. 极端高温事件识别

### 5.1 阈值定义

采用 **90% 分位数阈值法**（P90）：
1. 对每个格点，以 2010–2022 年夏季所有日值作为样本
2. 取第 90 百分位数作为该格点的高温阈值

### 5.2 热浪定义

**热浪事件** = 连续 3 天及以上日最高温超过 P90 阈值

### 5.3 极端高温指数

| 指数 | 英文 | 定义 | 单位 |
|------|------|------|------|
| 高温日数 | HWD (Hot Wave Days) | 每年夏季超过 P90 的总天数 | 天 |
| 热浪次数 | HWN (Heat Wave Number) | 每年夏季热浪事件次数 | 次 |
| 热浪持续时间 | HWDur (Heat Wave Duration) | 每次热浪的平均持续天数 | 天 |
| 累积高温强度 | HWI (Heat Wave Intensity) | 超过阈值的累积温度异常 | °C·天 |

### 5.4 逐年统计

绘制各指数的逐年变化序列，叠加线性趋势线。

## 8. 环流机制分析

### 8.1 环流合成分析

- 挑选极端高温年（如 2013、2017、2022）和低温年
- 合成分析高温年与低温年的 **500 hPa 位势高度距平场**
- **SLP 距平场** 和 **风场距平**

### 8.2 环流分型（聚类分析）

使用 K-means 或层次聚类对每日 500 hPa 位势高度场进行分类：

- 确定最优聚类数（肘部法则 + 轮廓系数）
- 分析每类环流型对应的气温异常特征
- 统计每类环流型的出现频率年际变化

### 8.3 副热带高压诊断

- 计算 **西太平洋副高强度指数**：500 hPa 位势高度 > 5880 gpm 的区域平均
- 分析副高西伸脊点位置
- 副高强度与高温日数的相关性

### 8.4 海温遥相关

- 获取 Niño3.4 指数（来自 NOAA）
- 分析 ENSO 与中国夏季高温的滞后相关
- 绘制 **SST 与气温的相关场**
